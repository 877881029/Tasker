# Copilot 主题与详情体验（2026-10-10）

状态：**用户已批准**（2026-10-10 会话）。本规格替换 `2026-09-15-ui-contract-lock.md` 中的 §2 主题锁；§3 接口锁仍然有效，例外见本文 §5。

## 1. 目标

用户认为 Tasker 外观「手搓感」强，打开详情和详情内操作体验差，要求模仿 GitHub Copilot App 当前浅色主题：字色、边框、圆角、分区色阶、悬停与按下反馈。工具仅个人使用：**不加**写入/保存/收起按钮，快捷键 `Ctrl+I / Ctrl+S / Esc` 不变。紧急度与完成标记改为 Copilot 式的「状态胶囊 + 下拉菜单」。

## 2. 从 Copilot App 学到的规则

采样自用户附图：

- 分区靠**色阶 + 1px 分隔线**，没有阴影和粗外框：侧栏 `#f1ebe7`，主区 `#f6f2ee`，分隔线 `#e6dfda`。
- 列表是**无边框行**：常态透明，悬停浅填充，选中更深一级填充，6px 圆角。
- 图标按钮是**幽灵按钮**：无底无框，悬停才出现填充。
- 输入框近白底、1px 稍深边线、8px 圆角，焦点是蓝色环。
- 选择器是**文字胶囊 + 下拉**（如 `Interactive ▾`、模型选择）；危险操作放在不显眼位置。
- 字体 Segoe UI，正文深灰而非纯黑，次要文字暖灰。

## 3. 新主题（锁定）

`src/tasker/theme.py` 保留全部 token 名，替换数值，并新增 `HOVER`、`SELECTED`、`LINE_STRONG`、`UI_FONT`。

## 4. 布局与交互

### 4.1 外壳与分区

- 外壳 1px `LINE` 外框；打开详情时**不再**画 2px 蓝框（`bubble` 属性保留但不改变外框）。
- 右侧栏 `CHROME`，详情区 `PAPER`，两者之间 1px `LINE` 竖线（原 16px `notch` 收为 1px 分隔线，仍可拖窗）。

### 4.2 顶部工具栏

- 搜索框 34px、8px 圆角、`CARD` 底、`LINE_STRONG` 边线，聚焦 2px `COBALT` 环（沿用自绘方案，去系统底线）。
- `+` / 置顶 / 隐藏改为 32×32 幽灵按钮：常态透明；悬停 `HOVER`；按下 `SELECTED`；置顶开启 `SELECTED` 底；键盘焦点 2px `COBALT` 环。

### 4.3 任务行

- 无边框行，最小高度 40px，内边距 10/8，状态圆点 10px 与首行文字居中对齐，标题 14px。
- 常态透明；悬停 `HOVER`；选中（当前打开）`SELECTED`；键盘焦点 2px `COBALT` 环。已完成标题用 `MUTED`。
- 右键弹出状态菜单：普通 / 紧急 / 已完成（当前项打勾）。

### 4.4 详情头部

- 左：**状态胶囊** `● 普通 ▾`，底色/边线随状态（普通绿、紧急红、已完成灰）。点击弹出与右键相同的状态菜单。原 32px 大圆点与「完成」复选框合并到此。
- 中：标题——无框大字（20px，600），悬停 `HOVER` 底，聚焦 `CARD` 底 + `COBALT` 环。
- 右：删除为 32px 幽灵垃圾桶图标；首次点击变为红色胶囊「确认删除」，4 秒内再点才删除（沿用两步确认）。

### 4.5 详情底栏（替代头部下方提示）

- 底部 1px `LINE` 上分隔，左侧显示模式：只读 `Ctrl+I 写入 · Ctrl+S 保存 · Esc 收起`；写入中 `● 正在写入 · Ctrl+S 保存 · Esc 保存并收起`（圆点 `COBALT`）；保存后 `已保存 HH:MM · Ctrl+I 继续写入`。12px `MUTED`。

### 4.6 打开详情的流畅度

- 点击任务时**只更新选中态**，不重建整个列表，滚动位置和焦点保持不动；仅在数据变化（标题、状态、删除、新建、搜索）时重建。

### 4.7 菜单

托盘菜单和状态菜单统一：`CARD` 底、`LINE` 边、8px 圆角、项 6px 圆角、悬停 `HOVER`。

## 5. 接口变化（批准的例外）

- `DetailWindow` 头部：去掉 `done` 复选框与 32px `importance` 圆点，新增 `status_btn`（状态胶囊）。`importance` 名称保留给胶囊内部圆点不再要求。
- 新增 `tasker.shell.status.apply_status(store, item_id, target) -> Item`，只用现有 `Store.set_done` / `cycle_color` 实现，不改 `Store` 接口与磁盘格式。
- 其余公开 API、对象名、快捷键、托盘、单实例、几何行为、Markdown 日志格式保持不变。

## 6. 不做

不加写入/保存/收起按钮；不加新快捷键；不改数据格式；不引入阴影、渐变、动画；不做深色模式。
