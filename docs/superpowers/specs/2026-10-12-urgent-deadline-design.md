# 紧急任务 DDL 倒计时（设计）

日期：2026-10-12　状态：用户需求确认（2026-10-12 对话），实现中

## 需求

1. 紧急任务可在详情里设置 DDL（截止时间）。
2. 列表中该任务右侧显示 DDL 倒计时胶囊，样式参考 Copilot「Manage sessions」按钮：浅底、1px 描边、圆角、深色字。
3. 倒计时格式 `03d-14h-57m`（天-时-分，两位补零，天数超过 99 照常显示）。
4. 紧急任务自动按 DDL 先后排序（越近越靠前）。

## 决策

- 数据：任务 Markdown front matter 新增 `deadline:`，本地时间 ISO 字符串 `2026-10-15T18:00`；无 DDL 时不写该行。旧文件无此键 → 无 DDL，向后兼容。
- 仅 `state == urgent` 时：详情显示 DDL 控件、列表显示倒计时、参与 DDL 排序。改为普通/已完成时保留 `deadline` 但隐藏；改回紧急恢复显示。
- 详情：状态胶囊右侧加 DDL 胶囊按钮（与状态胶囊同高 26px）。未设置时显示「设置 DDL ▾」，设置后显示「DDL 10-15 18:00 ▾」。点击弹出与状态菜单同风格菜单：今天 18:00、明天 18:00、3 天后 18:00、下周一 09:00、自定义…（日期时间编辑框，回车或关闭菜单生效）、清除 DDL。不新增快捷键，不加保存按钮。
- 列表：倒计时胶囊放在标题右侧、顶部对齐；每 30 秒刷新文本（分钟精度）。
  - 正常：`CARD` 底、`LINE_STRONG` 描边、`INK` 字，8px 圆角，12px 600。
  - 24 小时内：字色 `URGENT_DOT`。
  - 已超期：显示 `超期 01d-02h-03m`，`URGENT_BG` 底、`URGENT_LINE` 描边、`URGENT_DOT` 字。
- 排序：紧急组内 有 DDL（按 DDL 升序）→ 无 DDL（按更新时间降序）；普通、已完成组不变。
- 主题仅使用现有色板，无阴影/渐变/动画。

## 不做

- 提醒通知、重复任务、时区处理（一律本地时间）。
