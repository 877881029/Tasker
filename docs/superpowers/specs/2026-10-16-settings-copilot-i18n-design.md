# 1.0.26：设置页对齐 Copilot + 中英文切换 设计

日期：2026-10-16　状态：用户已批准

## 设置页视觉（对齐 Copilot 设置）

- 无系统标题栏的独立窗口：12px 圆角、1px `LINE_STRONG` 边框；可拖动标题区/侧栏移动，拖边缘缩放；右上角关闭按钮，Esc 关闭。
- 左侧栏（`CHROME`）：Tasker 图标 + 版本、「搜索设置…」框、带线性图标的导航（通用 / 快捷键 / 功能说明 / 数据），选中项 `SELECTED` 圆角底，常规字重。
- 右侧（`PAPER`）：页标题 16px 半粗 + 灰色说明；小节标题 14px 半粗；行无卡片无分隔线：标题 14px 常规、说明 13px `MUTED`，控件靠右；内容最大宽 860。
- 开关 40×22，开为 `COBALT`；按钮 `CARD` 底 1px 边框 6px 圆角；固定按键用键帽样式。
- 搜索：按标题/说明/小节过滤行，隐藏无匹配的分类并跳到第一个有匹配的分类，无结果显示「没有匹配的设置」。

## 中英文切换

- 设置 → 通用 → 语言：中文 / English。存 `settings.json` 的 `language`，切换后出现「立即重启」，重启后整个界面（列表、详情、菜单、托盘、通知、设置、周报标题）使用新语言。
- 实现：`tasker.i18n.tr()`，中文原文为键，英文表 `EN`；测试保证所有 `tr()` 文本都有英文且占位符一致。
- 搜索关键词同时支持英文：urgent / normal / done / overdue / today / ddl。
- 重启：新进程带 `--restart` 启动，最多等 8 秒接管单实例。
