# 便捷功能包（10 项）设计

日期：2026-10-12　状态：用户已批准（「1-10 全部实现」）

原则：不增加学习成本。不加新的工具栏按钮，只用已有入口（托盘菜单、右键菜单、快捷键、列表）。只用现有色板，不加阴影、渐变或动画。

## 1. DDL 到点提醒 + 托盘角标

- 紧急任务有 DDL 时，在截止前 1 小时内（还没到期）弹一次「即将截止」托盘通知，到期时再弹一次「已超期」通知。
- 每个任务、每种提醒、每个 DDL 值只弹一次；改了 DDL 会重新计时。记录只存在内存里。
- 刚启动时如果已有超期任务，只弹一条汇总：「有 N 个任务已超期」，不逐条刷屏。
- 点击通知会打开对应任务；如果是汇总通知，则只显示列表。
- 托盘图标在超期数大于 0 时，右下角叠加一个红色圆点角标（`URGENT_DOT` 色，显示数字，超过 9 显示 `9+`）。托盘提示文字为「Tasker · N 个任务已超期」。
- 和列表倒计时共用 30 秒定时器。

## 2. 全局快捷键快速记录

- 默认注册 `Win+Alt+T`；注册失败就退回 `Ctrl+Alt+T`。实现方式：`RegisterHotKey` 加原生事件过滤器。
- 按下后，在当前屏幕上方三分之一处弹出无边框小输入框（480 宽，`CARD` 底，1px `LINE_STRONG` 边框，8px 圆角）。输入框下方一行灰字提示：「回车保存 · Esc 取消 · 以 ! 开头设为紧急」。
- 回车会创建任务并关闭输入框，不打开详情，同时刷新列表。空内容回车等于取消。
- 以 `!` 或 `！` 开头时，去掉前缀，把状态设为紧急。
- 托盘菜单增加「快速记录（<当前快捷键>）」。

## 3. 列表右键直接设 DDL

- 紧急任务的右键菜单在状态项之后加分隔线和「DDL ▸」子菜单，内容与详情里的 DDL 菜单相同（预设、自定义、清除）。
- 选择后保存、刷新列表重新排序；如果该任务的详情正开着，详情里的 DDL 胶囊同步更新。

## 4. 删除可撤销

- 详情的垃圾桶点一次就删除，取消原来的「确认删除」两步。列表中按 `Del` 也会删除当前选中的任务。
- 删除前把 `.md` 原文快照保存在内存里。列表底部浮出提示条：「已删除「标题」 撤销」，5 秒后消失。
- 点「撤销」或在 5 秒内按 `Ctrl+Z`，会原样写回文件，并刷新列表。
- 新的删除会替换掉旧的提示，只保留最近一次可撤销。
- 新增 `Store.read_raw(item_id) -> str | None` 和 `Store.restore_raw(item_id, raw) -> Item | None`。

## 5. 已完成折叠

- 列表末尾的已完成任务收进一行「已完成 (N) ▸」（objectName `doneToggle`），默认收起，点一下展开/收起，状态只存在内存里。
- 搜索框有内容时，已完成的匹配项总是展开显示。
- 没有已完成任务时不显示这一行。
- 当前正打开的已完成任务所在分组会自动展开。

## 6. 键盘全流程

| 键 | 作用 |
|---|---|
| `↓` / `↑`（列表或搜索框中） | 在任务间移动焦点；搜索框按 `↓` 进入第一项，第一项按 `↑` 回到搜索框 |
| `Enter` / `Space` | 打开（已有） |
| `Ctrl+N` | 新建（同 `+`） |
| `Ctrl+F` | 聚焦搜索框 |
| `Del` | 删除当前焦点任务（可撤销） |
| `Ctrl+Z` | 撤销最近一次删除（5 秒内） |
| `Ctrl+Shift+C` | 复制本周周报 |
| `Esc`（详情未打开） | 隐藏到托盘；搜索框有文字时先清空；已钉住时不隐藏（钉住即常驻置顶） |

## 7. 搜索更深

- 正文本来就参与搜索。新增几个关键词，结果与文字匹配取并集：

  | 关键词 | 匹配 |
  |---|---|
  | `紧急` | state=urgent |
  | `普通` | state=pending |
  | `已完成` / `完成` | state=done |
  | `超期` | 紧急且 DDL 已过 |
  | `今天` | 紧急且 DDL 是今天 |
  | `ddl`（不分大小写） | 紧急且设了 DDL |

- 关键词匹配后，排序规则不变。
- 搜索框提示文字改为「查找任务或日志…」，悬停提示列出上面这些关键词。

## 8. 一键导出周报

- 托盘菜单「复制本周周报」，或在窗口内按 `Ctrl+Shift+C`。
- 统计范围是本周一 00:00 到现在内、日志时间戳落在其中的记录，按任务汇总成 Markdown，写入剪贴板。列表底部提示「已复制本周周报（N 个任务）」。
- 格式：

  ```markdown
  # 周报 2026-10-12 ~ 2026-10-18
  ## 紧急
  ### 标题（DDL 10-16 18:00）
  - 10-12 3PM：第一行
    续行
  ## 普通
  ## 已完成
  ```

- 空分组省略。本周没有记录时，只输出标题和一行「本周暂无记录」。

## 9. 开机自启

- 托盘菜单增加勾选项「开机自启」，写入或删除 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Tasker`，值为带引号的冻结 exe 路径（开发态为 `python -m tasker`）。
- 菜单勾选状态读取注册表的实际值。

## 10. 最新日志摘要

- 任务行标题下方用 12px `MUTED` 灰字显示最新一条日志的第一行（即 `status_pin`），单行，超长用省略号。
- 图片 Markdown 显示为「[图片]」，空内容不显示这一行。

## 合同变更

`ui-contract-lock` 做以下调整：

- `Store` 增加 `read_raw` 和 `restore_raw`。
- 托盘菜单增加：快速记录、复制本周周报、开机自启。
- 任务行允许显示摘要行、DDL 胶囊和已完成折叠行。
- 删除改为一次点击加撤销。
