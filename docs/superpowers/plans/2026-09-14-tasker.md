# Tasker v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a local PySide6 Tasker: right-third dock of items, left detail with Markdown, cobalt T icon, `setup.ps1` launch, no Docker.

**Architecture:** SQLite store under `%LOCALAPPDATA%\Tasker` (tests use `TASKER_DATA_DIR`). Dock window sits on the right third of the screen; selecting an item opens a second window on the left two-thirds. Body is Markdown: `QPlainTextEdit` edit + `QWebEngineView` visual (`markdown-it-py` HTML, paper CSS). Paste writes PNG under `attachments/<id>/` and inserts an image tag.

**Tech Stack:** Python 3.12+, PySide6, markdown-it-py, pytest / pytest-qt, Pillow, PowerShell `setup.ps1`.

### Task 3: SQLite store

**Files:**
- Create: `src/tasker/store.py`, `tests/test_store.py`

**Interfaces:**
- Produces:

```python
@dataclass(frozen=True)
class Item:
    id: str
    title: str
    state: str  # pending | urgent | done
    status_pin: str
    body_md: str
    created_at: float
    updated_at: float
    resume_state: str  # pending | urgent
```

`Store(db_path: Path)` with `create() -> Item` (empty title, pending, empty pin/body, resume_state pending), `get`, `save(Item) -> Item` bumping `updated_at`, `list_visible(query: str = "") -> list[Item]` (urgent, pending, done; within group `updated_at` desc; query casefolds into title or body; empty query shows all including done), `cycle_color(id) -> Item` (pending↔urgent; done unchanged), `set_done(id, done: bool) -> Item` (done True stores current non-done into `resume_state`; False restores `resume_state`), `write_paste_png(item_id: str, data: bytes) -> Path` under `attachments_dir` as `{uuid}.png`.
